    3 = MSG_OPCODE_TEXTDIALOGUE
        argument 2: side (0-1)
        argument 3: line
        argument 4: dialogue

        this is the actual fun part. it seems new lines arent handled automatically which is understandable cause this is a game from 20 years ago and i bet pcs wouldnt be able to automatically handle word wrapping
        thats why argument 3 exists :fire:
    4 = MSG_OPCODE_WAIT
        argument 2: frames to wait

        this is how touhou handles waiting to allow the player to read it. in msg1.txt (what im reading to get a understanding of this) its usually put to 300 frames
    5 = MSG_OPCODE_ANMINTERRUPT
        argument 2: side (0-1)
        argument 3: interrupt signal

        runs an interrupt signal on a portrait, making it do animations and such
        from what i got from reimu's dialogue .spec and the code...

        interrupt[1] = tween into scene (used at start of msg1), for reimu she comes from the left side of the screen
        interrupt[2] = character is not talking, no fade
        interrupt[3] = character is talking, fade in
        interrupt[4] = character is not talking, fade out
        interrupt[5] = character is not talking, no fade
    6 = MSG_OPCODE_ECLRESUME

        EXAMPLE: rumia swoops in on stage 1 after some dialogue has passed. this value is the reason why
